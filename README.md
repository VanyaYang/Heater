# Heater
Esp32Heater

Реле G7DA или аналог

Улитка 7530 ( желательно с регулировкой оборотов для того чтоб нре создавать вихри внутри камеры)

Нагреватель 200W + 220 V 

 KSD9700 на 130 °C - предохранитель перегрева

 100K - термосопротивление ( датчик температуры)

 ds18b20 - датчик температуры камеры

 корпус iHeater 100W

 комплект болтов

 Esp32 C5 devkit с керамической или печатной антенной или Esp 32 Nano с керамической антенной ( она компактнее)


 
Итак настройки: из файла прошивки-


Тут пины подключения согласно им нужно подключить датчики к плате.
#define NTC_PIN 4           // Датчик 1: Термистор NTC 100k на нагревателе (Аналоговый)
#define ONE_WIRE_BUS 6      // Датчик 2: DS18B20 в камере принтера (Пин 6, RMT)
#define SSR_PIN 25          // Сигнал управления для твердотельного реле G7DA



Лимиты безопасности по сути их можно менять - максимальную температуру можно задрать 130 или 150, а начало плавного снижения на 5 градусов ниже максимальной для более быстрого нагрева
// Жесткие лимиты безопасности
const float MAX_HEATER_LIMIT = 110.0;  // Максимальный потолок для самого PTC
const float START_BRAKING_TEMP = 95.0; // Начинаем плавно снижать мощность с 95°C
bool emergencyShutdown = false;
